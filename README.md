# Taiwo Olawale | Portfolio

A fast, responsive, single-page portfolio for Taiwo Olawale, a freelance web developer in Lagos. Built with vanilla HTML, CSS, and JavaScript. No build step or framework required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. For example, run `python -m http.server 8000` here and visit `http://localhost:8000`.

## Update projects and links

- Edit the project cards in `index.html`. Duplicate the `.next-card` or `.project-card` markup to add work, and update the title, description, tags, and live/source links.
- Replace the LinkedIn placeholder URL in the footer with Taiwo's exact profile URL.
- Update the email, GitHub, or other profile links in `index.html` if they change.
- The hero monogram uses initials only. If Taiwo wants a photo, replace the `.hero-art` monogram in `index.html` with an appropriately sized, optimized image and useful alt text.
- Adjust colors, typography, spacing, and breakpoints in `styles.css`. Navigation and reveal effects are in `script.js`.

## GitHub Pages

This repository is plain static site content. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site will be served from the repository's GitHub Pages URL. There is no build command.
